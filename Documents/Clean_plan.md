## 🧩 三、数据清洗操作记录

| 步骤 | 清洗目标           | 方法/函数                       | 备注                                 |
| ---- | ------------------ | ------------------------------- | ------------------------------------ |
| 1    | 处理缺失值         | `df.fillna()` / `df.dropna()`   | 说明替换策略（均值、中位数、众数等） |
| 2    | 删除重复值         | `df.drop_duplicates()`          |                                      |
| 3    | 异常值处理         | 箱线图检测 / IQR 方法 / Z-score | 说明处理方式（删除/修正）            |
| 4    | 转换数据类型       | `pd.to_datetime()` / `astype()` |                                      |
| 5    | 格式标准化         | `str.strip()` / `str.lower()`   | 统一大小写、去除空格等               |
| 6    | 类别统一           | 替换拼写或缩写                  | 例如 “M”、“male” → “Male”            |
| 7    | 新特征衍生（可选） | 从日期中提取“星期几”            |                                      |
